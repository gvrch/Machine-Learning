# Reinforcement Learning-Based Adaptive-Gain Attitude Control for a Nadir-Pointing CubeSat

This repository contains the development and evaluation of a reinforcement learning-based attitude control strategy for a nadir-pointing CubeSat.

The proposed architecture combines a conventional PD controller with a Proximal Policy Optimization (PPO) agent that adapts the proportional and derivative gains online. The objective is to improve robustness under model uncertainty, actuator degradation, environmental disturbances, and impulsive events while preserving the interpretability and stability structure of a classical feedback controller.

## Overview

The spacecraft operates in Low Earth Orbit and is required to maintain nadir pointing, with the body-frame \(+x\) axis aligned with the Earth-pointing direction.

Two control strategies are compared:

- **Fixed-gain PD controller** — baseline controller designed from the nominal spacecraft inertia.
- **RL-adaptive PD controller** — PPO adjusts \(K_p\) and \(K_d\) online while the control torque is still generated by the PD law.

The reinforcement learning agent therefore does **not** directly command the actuator torque. Instead, it adapts the controller gains according to the current spacecraft state and operating conditions.

## Control Architecture

The baseline PD gains are obtained from a second-order design:

\[
K_p = I\omega_n^2,
\qquad
K_d = 2\zeta\omega_n I
\]

with nominal design parameters

\[
\omega_n = 0.4,
\qquad
\zeta = 0.9.
\]

The nominal spacecraft inertia is

\[
I_{\mathrm{nom}} =
\mathrm{diag}
\left(
0.058816667,\;
0.054000375,\;
0.011250375
\right)\;\mathrm{kg\,m^2}.
\]

The PPO policy outputs adaptive gain corrections rather than direct control torques. This preserves the structure of a classical PD controller while allowing the controller to react to changing operating conditions.

## Simulation Environment

The spacecraft model includes nonlinear rotational dynamics and representative environmental disturbances:

- gravity-gradient torque;
- aerodynamic drag;
- solar radiation pressure;
- magnetic disturbance torque;
- impulsive collision-like disturbances.

The simulations also include uncertainty in the spacecraft initial conditions and inertia properties.

## Fault Scenarios

Robustness is evaluated under both nominal and faulty conditions.

The main fault cases include:

- **reaction-wheel degradation**, represented through a reduced actuator effectiveness;
- **impulsive angular-rate disturbances**, applied during the simulation;
- combined actuator and disturbance scenarios.

These cases are used both during curriculum training and during the final Monte Carlo evaluation.

## Reinforcement Learning

The adaptive controller is trained using **Proximal Policy Optimization (PPO)**.

A curriculum-based training strategy is adopted. The initial stage allows the agent to learn gain adaptation from nominal PD tracking behaviour before progressively introducing increasingly difficult operating conditions such as reaction-wheel degradation and impulsive disturbances.

The PPO controller therefore learns how to modify the PD gains while remaining embedded within the conventional feedback-control architecture.

## Monte Carlo Evaluation

The fixed-gain and RL-adaptive controllers are benchmarked through Monte Carlo simulations including variations in:

- initial spacecraft attitude;
- initial angular velocity;
- spacecraft inertia;
- reaction-wheel effectiveness;
- impulsive disturbance magnitude and timing.

The main performance metrics are:

- failure rate;
- peak pointing error;
- recovery time after a disturbance;
- robustness across the actuator-fault / impulsive-disturbance space.

This allows the adaptive controller to be evaluated not only under nominal conditions but also across a broad range of off-nominal scenarios.

## Repository Contents

The repository contains the simulation environment, controller implementation, PPO training workflow, and scripts used to compare the fixed-gain and adaptive controllers.

The project is organized around three main activities:

1. modelling the spacecraft dynamics and disturbances;
2. training the PPO adaptive-gain controller;
3. evaluating the controller through nominal and fault Monte Carlo campaigns.

## Project Context

Academic project focused on the application of reinforcement learning to spacecraft Guidance, Navigation and Control, with particular attention to combining data-driven adaptation with a conventional feedback-control architecture.
